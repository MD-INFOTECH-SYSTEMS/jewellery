# Rajwada - Premium Royal Jewellery E-Commerce

A production-level, responsive jewellery e-commerce website frontend inspired by ancient Indian palace/heritage architecture.

## Tech Stack
- HTML5
- Tailwind CSS (via CDN for simplicity, configured for custom theme)
- Vanilla JavaScript (Modular Architecture)

## Features
- Responsive Design (Mobile, Tablet, Desktop)
- Mega Menu Navigation
- Image Carousel with Auto-play
- Interactive Product Cards with Quick View Modal
- Wishlist System (using LocalStorage)
- Shopping Cart System (using LocalStorage)
- Dynamic Search Filtering
- Custom Toast Notifications
- CSS Grid & Flexbox Layouts
- Royal Heritage Theme (Maroon, Gold, Ivory, Pink)

## File Structure
```
jewellery-store/
│
├── index.html
│
├── css/
│   └── styles.css
│
└── js/
    ├── app.js (Main Initialization)
    ├── products.js (Demo Data)
    ├── cart.js (Cart Logic)
    ├── wishlist.js (Wishlist Logic)
    ├── search.js (Search Overlay & Filtering)
    ├── carousel.js (Hero Banner Carousel)
    ├── modal.js (Quick View Modal)
    └── toast.js (Toast Notifications)
```

## How to Run
1. Open `index.html` in any modern web browser.
2. (Optional) Run a local development server, e.g., `npx http-server` or VS Code Live Server for the best experience.
